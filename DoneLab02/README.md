### Задание 2 **(2)**
*Рассмотрим следующие фрагменты программ на языках С++ и Python.*

**C++**
```cpp
int main() {
   int a=1, b=2;
   int c=a++b;
   return 0;  
}
```

**Python**
```python
a=1
b=2
c=a++b
```
*Запишите эти программы и выполните их трансляцию (запуск). Запишите в отчет сообщения об ошибках.*

*Разбейте эти программы на последовательности токенов и объясните, почему программа на C++ содержит синтаксическую ошибку, а программа на Python — нет.*

#### Ответ:

1. **Результаты трансляции и сообщения об ошибках:**
   * **C++:** Трансляция завершается с ошибкой компиляции:
     `error: lvalue required as increment operand` (или `error: invalid series of operators`).
   * **Python:** Программа транслируется и выполняется **успешно** без ошибок (`c` получает значение `3`).

2. **Последовательности токенов:**
   * **C++:** `[int]` `[main]` `[(]` `[)]` `[{]` `[int]` `[a]` `[=]` `[1]` `[,]` `[b]` `[=]` `[2]` `[;]` `[int]` `[c]` `[=]` `[a]` `[++]` `[b]` `[;]` `[return]` `[0]` `[;]` `[}]`
   * **Python:** `[a]` `[=]` `[1]` `[NEWLINE]` `[b]` `[=]` `[2]` `[NEWLINE]` `[c]` `[=]` `[a]` `[+]` `[+]` `[b]` `[NEWLINE]`

3. **Объяснение причин:**
   * **Принцип «жадного поглощения» (Maximal Munch / Принцип наибольшей длины):** Лексический анализатор (токенизатор) читает символы слева направо и формирует самый длинный из возможных легальных токенов.
   * **В C++:** Встречая подряд символы `+` и `+`, токенизатор C++ объединяет их в единый токен инкремента `++`. Из выражения `a++b` формируется цепочка токенов `[a] [++] [b]`. Поскольку оператор `++` является унарным, а токенизатор расположил его между двумя операндами `a` и `b`, возникающий синтаксический контекст противоречит КС-грамматике языка.
   * **В Python:** В языке Python **нет** операторов инкремента и декремента (`++` или `--`). Токенизатор Python не знает токена `++`, поэтому разбирает два плюса как два независимых оператора `+` и `+`. Выражение `a++b` интерпретируется как `a + (+b)` — сложение переменной `a` и унарного плюса переменной `b` ($1 + (+2) = 3$), что полностью соответствует грамматике Python.

Разбейте эту программу на токены и объясните ее работу.*

*Можно ли изменить разбиение этой программы на токены, вставляя пробелы? Если да, то выполните эти изменения и проверьте работу измененной программы.*

#### Ответ:

1. **Значения переменных после выполнения:**
   * `a = 2` (переменная инкрементирована)
   * `b = 2` (значение не изменилось)
   * `c = 3` (результат выражения $1 + 2$)

2. **Токенизация и объяснение работы:**
   * **Последовательность токенов:** `[int]` `[c]` `[=]` `[a]` `[++]` `[+]` `[b]` `[;]`
   * **Объяснение:** По правилу наибольшей длины токенизатор считывает первые два знака `+` как унарный постфиксный инкремент `++`, а третий знак `+` — как бинарный оператор сложения `+`. Выражение вычисляется как `(a++) + b`. Сначала берётся текущее значение `a` ($1$), складывается с `b` ($2$), результат ($3$) присваивается `c`, после чего `a` увеличивается на $1$ и становится равным $2$.

3. **Изменение разбиения токенов с помощью пробелов:**
   Да, вставляя пробелы, можно изменить лексический разбор выражения:
   * **Вариант 1 (`a + ++b;`):**
     ```cpp
     int c = a + ++b;
     ```
     * **Токены:** `[a]` `[+]` `[++]` `[b]`
     * **Результат:** Сначала префиксно инкрементируется `b` ($b$ становится $3$), затем складывается с `a` ($1$). В результате: `a = 1`, `b = 3`, `c = 4`.
   * **Вариант 2 (`a + + + b;`):**
     ```cpp
     int c = a + + + b;
     ```
     * **Токены:** `[a]` `[+]` `[+]` `[+]` `[b]`
     * **Результат:** Две операции унарного плюса над `b` и бинарное сложение. В результате: `a = 1`, `b = 2`, `c = 3`.

### Задание 4 **(2)**
*В каком случае круглые и квадратные скобки являются операторами?
Приведите примеры фрагментов программ, в которых круглые скобки являются оператором и примеры 
программ, в которых они оператором не являются.*

#### Ответ:
Скобки являются **операторами**, когда они обозначают явное действие над операндами (вызов функции, индексация элемента, явное приведение типов, захват контекста). Они являются **пунктуаторами (синтаксическими разделителями)**, когда организуют структуру синтаксических конструкций языка (заголовки циклов, условий, списки параметров при объявлении функций и массивов).

1. **Круглые скобки `()`:**
   * **Являются оператором:**
     * *Оператор вызова функции:* `int res = abs(a);` или `foo(x, y);` (вызывают выполнение блока кода).
     * *Оператор приведения типов (в стиле C):* `int x = (int) 3.14;`
     * *Оператор конструирования объекта:* `std::string s("text");`
   * **НЕ являются оператором:**
     * *Синтаксические разделители в управляющих инструкциях:* `if (x > 0)`, `while (a < b)`, `for (int i=0; i<10; i++)`.
     * *Группировка приоритета вычислений:* `int c = (a + b) * 2;` (здесь скобки задают порядок операций и выступают знаками пунктуации).

2. **Квадратные скобки `[]`:**
   * **Являются оператором:**
     * *Оператор индексации:* `arr[0] = 5;`, `v[i]` (операция взятия элемента по смещению/ключу).
     * *Захват в лямбда-выражениях C++:* `auto f = [x, &y]() { return x + y; };`
   * **НЕ являются оператором:**
     * *Объявление массива (задание размера):* `int arr[10];` (задает синтаксический размер типа при объявлении).

### Задание 5 **(3)**
*Рассмотрим следующую программу на языке Python.*
```python
print(*map(sum,zip(
    *[map(int,input().split()) for i in (1,2,3)]
    )))
```
*Найдите в этой программе ключевые слова, идентификаторы, литералы, операторы.
Какие из идентификаторов задают переменные, а какие - имена функций и методов?
Перечислите все функции, которые вызываются в этом фрагменте кода и их параметры.
Что делает эта программа, и как она приходит к результату?*

#### Ответ:

1. **Классификация токенов:**
   * **Ключевые слова:** `for`, `in`.
   * **Идентификаторы:** `print`, `map`, `sum`, `zip`, `int`, `input`, `split`, `i`.
     * *Переменная:* `i` (переменная цикла).
     * *Имена функций и типов:* `print`, `map`, `sum`, `zip`, `int`, `input`.
     * *Имя метода:* `split`.
   * **Литералы:** `1`, `2`, `3` (целочисленные литералы).
   * **Операторы:** `*` (оператор распаковки), `.` (оператор доступа к атрибуту/методу).

2. **Вызываемые функции/методы и их параметры:**
   1. `input()` — вызывается без параметров; возвращает введенную пользователем строку.
   2. `split()` — метод строки, вызывается без параметров у результата `input()`; разбивает строку на список подстрок по пробелам.
   3. `map(int, ...)` — параметры: тип/функция преобразования `int` и список строк от `split()`. Преобразует строки в целые числа.
   4. `zip(*[...])` — параметр: распакованный список из 3 итераторов `map`, созданных списковым включением `[... for i in (1,2,3)]`.
   5. `map(sum, ...)` — параметры: встроенная функция `sum` и итератор `zip`. Вычисляет сумму элементов в каждой сгруппированной кортеж-строке.
   6. `print(*...)` — параметр: распакованные результаты внешнего `map`. Выводит полученные суммы через пробел.

3. **Алгоритм работы и назначение программы:**
   Программа запрашивает у пользователя ввод **3 строк** с числами, представляющими матрицу размером $3 \times N$, и вычисляет **постолбцовые суммы** (сумму элементов каждого столбца), выводя результат в одну строку через пробел.
   * *Шаг 1:* В генераторе `[map(...) for i in (1,2,3)]` считываются 3 строки через `input()`, разбиваются на подстроки и преобразуются в 3 итератора с числами.
   * *Шаг 2:* Оператор `*` перед списком распаковывает эти 3 итератора как 3 отдельных аргумента для функции `zip`.
   * *Шаг 3:* `zip` группирует элементы с одинаковыми индексами (транспонирует матрицу), собирая числа $j$-го столбца из всех 3 строк в единый кортеж.
   * *Шаг 4:* Внешний `map(sum, ...)` применяет функцию `sum` к каждому кортежу, получая сумму по каждому столбцу.
   * *Шаг 5:* Оператор `*` распаковывает результаты сумм в аргументы `print`, который печатает их через пробел.

### Задание 6 **(2)**
*Как можно записывать комментарии на С++?*

*Какие из приведенных ниже примеров являются синтаксически неверными (вызывают ошибки при трансляции)?
Почему? Как работают синтаксически верные примеры?*

```cpp
cout<<"Hello /* Это комментарий */ world";
```

```cpp
// /*
 Это комментарий
*/
```

```cpp
/* Я комментирую программы /* комментарий */ */
```

```cpp
// Я комментирую программы /* комментарий */  
```

```cpp
/* Я комментирую свои программы
// Это комментарий до конца строки */
*/
```

#### Ответ:

1. **Способы записи комментариев в C++:**
   * **Однострочные:** начинаются с последовательности `//` и действуют до конца текущей строки.
   * **Многострочные (блочные):** начинаются с `/*` и продолжаются до закрывающей последовательности `*/`.

2. **Анализ примеров:**

   * **Пример 1:** `cout<<"Hello /* Это комментарий */ world";`
     * **Синтаксически ВЕРЕН.** Последовательность `/* ... */` находится внутри двойных кавычек и воспринимается токенизатором как часть **строкового литерала**, а не как комментарий. На консоль выведется текст: `Hello /* Это комментарий */ world`.

   * **Пример 2:**
     ```cpp
     // /*
      Это комментарий
     */
     ```
     * **Синтаксически НЕВЕРЕН (ошибка компиляции).** Первая строка закомментирована через `//`, поэтому символы `/*` игнорируются и не открывают блочный комментарий. На второй строке текст `Это комментарий` компилятор пытается распознать как C++ код. На третьей строке символы `*/` вызывают ошибку, так как нет открытого `/*`.

   * **Пример 3:** `/* Я комментирую программы /* комментарий */ */`
     * **Синтаксически НЕВЕРЕН (ошибка компиляции).** Многострочные комментарии в C++ **не могут быть вложенными**. Первый `/*` открывает комментарий, а первый встретившийся `*/` сразу его закрывает. Оставшаяся часть `*/` в конце строки оказывается вне комментария и приводит к ошибке компиляции.

   * **Пример 4:** `// Я комментирую программы /* комментарий */`
     * **Синтаксически ВЕРЕН.** Вся строка после `//` игнорируется компилятором, включая входящие в нее символы `/*` и `*/`.

   * **Пример 5:**
     ```cpp
     /* Я комментирую свои программы
     // Это комментарий до конца строки */
     */
     ```
     * **Синтаксически НЕВЕРЕН (ошибка компиляции).** Первая строка открывает многострочный комментарий `/*`. Символы `//` на второй строке игнорируются, так как находятся внутри закрываемого блока. В конце второй строки закрывается комментарий `*/`. Символы `*/` на третьей строке остаются вне комментария и вызывают синтаксическую ошибку.

### Задание 7 **(4)**
*Найдите в стандарте С++*

[http://www.open-std.org/jtc1/sc22/wg21/docs/papers/2017/n4659.pdf]

*в приложении* **A.5** *формальные синтаксические правила для 
инструкций циклов* **iteration-statement.** *Опишите на естественном языке каждую строчку
из этих правил. Для каждой строчки из правила приведите короткий пример фрагмента программы,
которая построена по этому правилу.*

#### Ответ:

Как видно из правил стандартов, есть **4** инструкции циклов.

1. **Первый вид** — цикл с предусловием **while**, который соответствует строке правила:
   $$\text{while ( condition ) statement}$$
   * **Формат записи:** ключевое слово `while`, в круглых скобках условие `condition`, далее инструкция `statement`.
   * **Пример:**
     ```cpp
     int x = 1;
     while (x < 1000) {
         cout << x;
         x *= 2;
     }
     ```

2. **Второй вид** — цикл с постусловием **do-while**, который соответствует строке правила:
   $$\text{do statement while ( expression ) ;}$$
   * **Формат записи:** ключевое слово `do`, далее инструкция `statement`, ключевое слово `while`, в круглых скобках выражение `expression`, завершающая точка с запятой `;`.
   * **Пример:**
     ```cpp
     int x = 1;
     do {
         cout << x;
         x *= 2;
     } while (x < 1000);
     ```

3. **Третий вид** — традиционный цикл **for**, который соответствует строке правила:
   $$\text{for ( init-statement condition}_{\text{opt}}\text{ ; expression}_{\text{opt}}\text{ ) statement}$$
   * **Формат записи:** ключевое слово `for`, в круглых скобках инструкция инициализации `init-statement`, необязательное условие `condition`, точка с запятой, необязательное выражение `expression`, далее инструкция `statement`.
   * **Пример:**
     ```cpp
     for (int i = 0; i < 10; i++) {
         cout << i;
     }
     ```

4. **Четвертый вид** — диапазонный цикл **range-for**, который соответствует строке правила:
   $$\text{for ( for-range-declaration : for-range-initializer ) statement}$$
   * **Формат записи:** ключевое слово `for`, в круглых скобках объявление переменной диапазона `for-range-declaration`, двоеточие `:`, инициализатор диапазона (коллекция) `for-range-initializer`, далее инструкция `statement`.
   * **Пример:**
     ```cpp
     for (int x : v) {
         cout << x;
     }
     ```
