*Составьте глоссарий из определений лекции. Проверка отчета будет включать проверку знания определений.*

#### Ответ (Глоссарий):

* **Тип в программировании** — атрибут объекта данных, задающий множество допустимых значений и методы для работы с ними[cite: 3].
* **Статическая типизация** — вид типизации, при котором тип объекта данных определяется на этапе трансляции (компиляции) программы[cite: 3] (по записи литерала, объявлению переменной или по оператору и типу операндов)[cite: 3].
* **Динамическая типизация** — вид типизации, при котором тип объекта данных определяется непосредственно на этапе выполнения программы (in runtime) в момент создания объекта или присваивания ему значения[cite: 3].
* **Неявная (утиная) типизация** — подход, при котором тип определяется автоматически по тексту программы на этапе трансляции или выполнения без явного указания типа разработчиком (по принципу: *«Если это выглядит как утка, плавает как утка и крякает как утка, то это утка»*)[cite: 3].
* **Явное преобразование типа** — метод преобразования значения одного типа в значение другого типа, явно указанный в тексте программы в виде вызова функции, конструктора или специальной операции[cite: 3].
* **Неявное преобразование типа** — автоматическая подстановка транслятором (компилятором) метода преобразования одного типа в другой без явного указания в коде программы[cite: 3].
* **Сильная типизация** — характеристика системы типов языка программирования, при которой язык практически не содержит правил неявного преобразования типов и строжайше запрещает недиагностируемые операции над несогласованными типами[cite: 3].
* **Слабая типизация** — характеристика системы типов языка программирования, при которой язык содержит большое количество правил неявного преобразования типов и допускает каламбуры типизации[cite: 3].

### Задание 2 **(3)**
*Запишите правила неявного преобразования типов в языке С++*

#### Ответ:

#### 1. Преобразования при присваивании
* **Присваивание значений:** При выполнении операции присваивания значение правого операнда автоматически приводится к типу левого операнда[cite: 3].
* **Вызов функций:** При передаче аргументов в функцию фактический параметр неявно приводится к типу формального параметра, указанного в объявлении функции[cite: 3].
* **Преобразование в `bool`:** Любое числовое значение или указатель преобразуется в `bool`: значение `0` (или `nullptr`) преобразуется в `false`, а любое ненулевое значение — в `true`[cite: 3].
* **Преобразование из `bool`:** Значение `false` неявно преобразуется в `0`, а `true` — в `1`[cite: 3].
* **Вещественные в целочисленные:** При приведении из вещественного типа (`float`, `double`) в целочисленный происходит отбрасывание (отсечение) дробной части[cite: 3].
* **Символьные типы:** Преобразования происходят по целочисленному коду символа (ASCII/Unicode)[cite: 3].

#### 2. Преобразования при арифметических действиях (Usual Arithmetic Conversions)
* **Целочисленное продвижение (Integer Promotion):** Если размеры типов обоих операндов меньше `int` (например, `char`, `short`), оба операнда неявно расширяются до типа `int` (или `unsigned int`)[cite: 3].
* **Разные длины:** Если операнды имеют разную длину (размер в байтах), операнд меньшей длины приводится к типу операнда большей длины[cite: 3].
* **Знаковый и беззнаковый типы одинаковой длины:** Если типы имеют одинаковую длину, но один является знаковым (`signed`), а другой — беззнаковым (`unsigned`), знаковый операнд неявно приводится к беззнаковому типом (`unsigned`)[cite: 3].
* **Целый и вещественный типы:** Если один из операндов целочисленный, а другой — вещественный (`float`, `double`, `long double`), целочисленный операнд преобразуется к вещественному типу[cite: 3].

#### 3. Преобразования с логическими значениями
* **Логический контекст:** Результат условных выражений в управляющих конструкциях (`if`, `while`, `for`), а также операнды логических операторов (`&&`, `||`, `!`) автоматически приводятся к типу `bool`[cite: 3].
* **Арифметические и битовые операции:** Если целочисленный оператор требует целого числа (сдвиги, остаток от деления `%`, битовые `&`, `|`), а передается `bool`, логическое значение промотируется в `int` (`false` $\rightarrow 0$, `true` $\rightarrow 1$)[cite: 3].

##### Пример 1: Использование целого числа в логическом условии
* **C++** (Компилируется и успешно работает):
  ```cpp
  int status = 5;
  if (status) { // Неявно преобразует int (5) в bool (true)
      // Код выполняется
  }
  ```
* **Java** (Ошибка компиляции `type mismatch: cannot convert from int to boolean`):
  ```java
  int status = 5;
  if (status) { // Ошибка! Java не приводит int к boolean неявно
      // ...
  }
  ```

##### Пример 2: Сужение целочисленных типов без явного приведения
* **C++** (Компилируется, старшие биты отбрасываются):
  ```cpp
  int bigVal = 100000;
  short shortVal = bigVal; // Неявное сжатие разрешено
  ```
* **Java** (Ошибка компиляции `incompatible types: possible lossy conversion from int to short`):
  ```java
  int bigVal = 100000;
  short shortVal = bigVal; // Ошибка! Требуется явный cast: (short) bigVal
  ```

##### Пример 3: Сложение `bool` и числового типа
* **C++** (Компилируется, `true` преобразуется в `1`):
  ```cpp
  bool flag = true;

  ```
* **Java** (Ошибка компиляции `operator + cannot be applied to int, boolean`):
  ```java

  ```

### Задание 4 **(1)**
*Определение типов переменных `a` и `b` с помощью `typeid`.*

#### Исходный код:
```cpp
#include <iostream>
#include <typeinfo>

int main() {
    bool x = true, y = false;
    auto a = x & y;
    std::cout << typeid(a).name() << std::endl;
    auto b = x && y;
    std::cout << typeid(b).name() << std::endl;
    return 0;
}
```

#### Результат выполнения:
* `typeid(a).name()` выводит: `i` (обозначает тип `int`).
* `typeid(b).name()` выводит: `b` (обозначает тип `bool`).

#### Объяснение:
1. **Для переменной `a = x & y`:** Оператор `&` является побитовым И (bitwise AND). По правилам C++, побитовые операции требуют целочисленных операндов[cite: 3]. Операнды типа `bool` (`x` и `y`) подвергаются целочисленному продвижению (Integer Promotion) до типа `int`[cite: 3]. Вычисляется выражение `(int)1 & (int)0 = 0` типа `int`. Выведенное имя `i` означает `int`.
2. **Для переменной `b = x && y`:** Оператор `&&` является встроенным логическим И (logical AND). Он принимает логические операнды и всегда возвращает результат типа `bool` (`false`)[cite: 3]. Выведенное имя `b` означает `bool`.

### Задание 6 **(2)**
*Анализ работы программы с неявными преобразованиями типов.*

```cpp
#include <iostream>

int main() {
    int a = -1, b = 1;
    unsigned int c = 1;
    std::cout << a * b << std::endl; // Вывод: -1
    std::cout << a * c << std::endl; // Вывод: 4294967295 (на 32-битной/64-битной системе)
    return 0;
}
```

#### 1. Объяснение работы:
* **Выражение `a * b`:** Оба операнда имеют тип `int`. Выполняется обычное умножение со знаком: $(-1) \cdot 1 = -1$.
* **Выражение `a * c`:** Операнд `a` имеет тип `int` (знаковый), а `c` — `unsigned int` (беззнаковый). По правилам арифметических преобразований при одинаковой длине знаковый `int` неявно преобразуется в `unsigned int`[cite: 3]. Значение `-1` в беззнаковом 32-битном представлении превращается в максимально возможное число $2^{32} - 1 = 4294967295$[cite: 3]. Далее происходит умножение $4294967295 \cdot 1 = 4294967295$.

#### 2. Что произойдет при замене на `short` и `unsigned short`:
Если заменить типы на `short a = -1, b = 1;` и `unsigned short c = 1;`, вывод второй строки изменится и станет равным **`-1`**.
* **Причина:** По правилу целочисленного продвижения (Integer Promotion), операнды типов меньше `int` (как `short`, так и `unsigned short`) перед выполнением операции умножения **автоматически преобразуются в `int`**[cite: 3]. В итоге выражение `a * c` вычисляется в контексте знакомого `int`: `(-1) * 1 = -1`.

### Задание 7 **(2)**
*Влияние порядка действий и правил преобразования типов на результат.*

```cpp
#include <iostream>

int main() {
    int x = 7, y = 4;
    long double d = 0.25;
    std::cout << (x / y) / d << std::endl; // Вывод: 4
    std::cout << (x / d) / y << std::endl; // Вывод: 7

    long a = 200000, b = 200000;
    long long c = 200000;
    std::cout << (a * b) * c << std::endl; // Потенциальное переполнение / мусор
    std::cout << a * (b * c) << std::endl; // Корректный результат: 8000000000000000
    return 0;
}
```

#### Объяснение:

1. **Первый блок (`(x / y) / d` против `(x / d) / y`):**
   * **Выражение `(x / y) / d`:** Сначала вычисляется скобка `(x / y)`. Так как `x` и `y` имеют тип `int`, выполняется **целочисленное деление**: $7 / 4 = 1$ (дробная часть отбрасывается)[cite: 3]. Затем $1 / 0.25$ вычисляется с приведением к `long double`, давая $4.0$.
   * **Выражение `(x / d) / y`:** В первой скобке `(x / d)` операнд `x` (`int`) неявно преобразуется к `long double` из-за `d`[cite: 3]. Вычисляется $7.0 / 0.25 = 28.0$. Затем $28.0 / 4$ (где `y` приводят к `long double`) дает $7.0$.

2. **Второй блок (`(a * b) * c` против `a * (b * c)`):**
   * **Выражение `(a * b) * c`:** Сначала умножаются `a` и `b` типа `long` (на 32-битных системах/MSVC размер `long` равен 4 байтам, макс. значение $\approx 2 \cdot 10^9$). Произведение $200000 \cdot 200000 = 40 \cdot 10^9$ выходит за границы типа `long` и вызывает **целочисленное переполнение** до усечения типа. Лишь затем результат умножается на `c` (`long long`).
   * **Выражение `a * (b * c)`:** Сначала вычисляется `(b * c)`. По правилу неявного приведения к большему типу, `b` (`long`) приводится к `long long` из-за `c`[cite: 3]. Умножение происходит в 64-битном типе без переполнения ($4 \cdot 10^{10}$), а затем умножение на `a` даёт корректное число $8 \cdot 10^{15}$.

```cpp
#include <iostream>

int main() {
    int x = 1, y = 1, z = 2;

    return 0;

```

#### Работа программы и неявные преобразования:
1. Результаты операторов сравнения `(x == y)` и `(x == z)` имеют тип `bool` (`true` или `false`).
2. Операция сложения `+` требует числовых операндов. Оба значения `bool` неявно преобразуются в `int`: `true` $\rightarrow 1$, `false` $\rightarrow 0$[cite: 3].
3. Сумма двух `bool` может принимать значения `0`, `1` или `2`.
4. Затем результат суммы (`int`) сравнивается с `true`. При сравнении `int` и `bool`, значение `true` неявно преобразуется в `1`[cite: 3]. Получаем равенство `Sum == 1`.

#### Значения переменной, при которых выражение истинно:
Выражение равно `true` тогда и только тогда, когда **ровно одно** из условий `(x == y)` или `(x == z)` истинно.
Все возможные случаи:
1. $x = y$ и $x \neq z$
2. $x \neq y$ и $x = z$

*(Если все три переменные равны $x = y = z$, то сумма $1 + 1 = 2$, а $2 == 1$ дает `false`)*.

### Задание 9 **(2)**
*Сравнение выражения `x == y == z` в Python, Java и C++.*

```python
# Python
x = 1
y = 1
z = 1
print(x == y == z) # Вывод: True
```

```java
// Java
public class Main {
    public static void main(String[] args) {
        int x = 1, y = 1, z = 1;
        // System.out.println(x == y == z); // ОШИБКА КОМПИЛЯЦИИ!
    }
}
```

```cpp
// C++
#include <iostream>

int main() {
    int x = 1, y = 1, z = 1;
    std::cout << std::boolalpha << (x == y == z) << std::endl; // Вывод: false
    return 0;
}
```

#### Объяснение результатов:

* **Python:** Поддерживает **цепочечные сравнения** (chained comparisons). Выражение `x == y == z` эквивалентно синтаксической конструкции `(x == y) and (y == z)`. Если $x=1, y=1, z=1$, вычисляется `True and True`, результат — **`True`**.
* **Java:** Операторы сравнения левоассоциативны. Сначала вычисляется `(x == y)`, что дает значение типа `boolean` (`true`). Далее Java пытается вычислить `true == z` (сравнение `boolean` и `int`). Так как Java обладает сильной типизацией и не преобразует `boolean` в числа, компилятор выдает **ошибку типов**[cite: 3].
* **C++:** Операторы также левоассоциативны. Выражение разбирается как `(x == y) == z`[cite: 3]. При $x=1, y=1$ выражение `(1 == 1)` даёт `true`. Затем `true` неявно преобразуется в `int` со значением `1`[cite: 3]. Вычисляется `1 == z` (`1 == 1`), что дает `true`. Однако если взять $x=2, y=2, z=2$, то `(2 == 2)` даст `true` ($1$), а $1 == 2$ вернет **`false`**! Поэтому в C++ данная конструкция работает синтаксически корректно из-за неявных приведений, но логически не проверяет равенство трех чисел.
