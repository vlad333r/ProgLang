### Задание 1 **(3)**
*Составьте глоссарий из определений лекции. Проверка отчета будет включать проверку знания определений*

* **Тип в программировании** — характеристика объекта данных, определяющая набор его возможных значений и список операций, которые над ним можно выполнять.
* **Статическая типизация** — подход, при котором тип каждой переменной и выражения устанавливается еще во время компиляции программы.
* **Динамическая типизация** — подход, когда тип данных связывается со значением прямо во время выполнения программы (при присваивании или создании объекта).
* **Неявная типизация** — концепция, где тип объекта выводится автоматически по контексту его использования, а не определяется явным объявлением (по принципу: *«если птица ходит, плавает и крякает как утка — значит, это утка»*).
* **Явное преобразование типа** — осознанное приведение значения из одного типа в другой, которое программист явно прописывает в коде через операторы или функции.
* **Неявное преобразование типа** — автоматическая подгонка типов, которую компилятор выполняет самостоятельно без вмешательства разработчика.
* **Сильная типизация** — строгость системы типов, при которой язык практически запрещает неявные приведения и сразу выдает ошибку, если типы операндов не совпадают.
* **Слабая типизация** — свойство языка, допускающее множество неявных приведений типов и разного рода «каламбуры типизации», когда одни и те же данные в памяти интерпретируются по-разному.

### Задание 2 **(3)**
*Запишите правила неявного преобразования типов в языке С++*

*Проверка отчета будет включать проверку знания правил.*

*Преобразования при присваивании*

*Преобразования при арифметических действиях*

*Преобразования с логическими значениями*

**Ответ.**

#### 1. Преобразования при присваивании
* **При присваивании:** Значение из правой части выражения автоматически приводится к типу переменной в левой части.
* **При вызове функций:** Передаваемые аргументы автоматически приводятся к типам параметров, указанным в заголовочной части функции.
* **Преобразование в `bool`:** Нулевые значения и нулевые указатели (`0`, `nullptr`) становятся `false`. Любые другие значения превращаются в `true`.
* **Преобразование из `bool`:** Логическое `false` переходит в числовой `0`, а `true` — в `1`.
* **Из вещественных в целые:** Дробная часть числа просто отбрасывается (происходит усечение, а не округление).
* **Символьные типы:** Приведение происходит по их числовым кодам в таблице символов.

#### 2. Преобразования при арифметических действиях
* **Целочисленное продвижение (Integer Promotion):** Если операнды имеют размер меньше `int` (к примеру, `char` или `short`), они автоматически расширяются до `int` (или `unsigned int`).
* **Разная длина операндов:** Если операнды разного размера, тип меньшего операнда подтягивается к типу большего.
* **Знаковый и беззнаковый типы:** Если размер типов совпадает, но один из них `signed`, а второй `unsigned`, знаковый операнд конвертируется в беззнаковый.
* **Целые и вещественные типы:** Если в операции участвуют целое и вещественное числа, целое число переводится в вещественный тип.

#### 3. Преобразования с логическими значениями
* **Логический контекст:** В условиях `if`, `while`, `for` и при использовании операторов `&&`, `||`, `!` выражения автоматически приводятся к типу `bool`.
* **Арифметика с `bool`:** Если передать `bool` в операцию, требующую целое число (битовые сдвиги, `%`, битовые И/ИЛИ), значение `bool` продвигается до `int` (`0` или `1`).

### Задание 3 **(2)**

*Языки C++ и Java имеют похожий синтаксис, однако
язык С++ относят к языкам со слабой статической типизацией, а Java - с сильной статической типизацией.
Приведите примеры, показывающие это различие. Для этого вам надо подобрать несколько близких по смыслу фрагментов программ,
которые будут транслироваться в С++, но вызывать ошибку согласования типов в Java.*

*Записанные программы сохраните в папке с номером задания. В отчет запишите пояснения к работе программ.*

**Ответ.**

##### Пример 1. Число в роли условия в `if`
* **C++** (код спокойно компилируется, `5` превращается в `true`):
  ```cpp
  int status = 5;
  if (status) {
  }
  ```
  Пояснение: В C++ целочисленное значение 5 в контексте условного оператора if автоматически преобразуется к типу bool. Любое число, не равное нулю, неявно интерпретируется как true, поэтому блок кода выполнится.
  
* **Java** (компилятор выдаст ошибку `incompatible types: int cannot be converted to boolean`):
  ```java
  int status = 5;
  if (status) { 
  }
  ```
  Пояснение: В Java выражение внутри if должно иметь строго тип boolean. В языке отсутствуют неявные преобразования из числовых типов в логические, поэтому компилятор выдаст ошибку.

##### Пример 2. Присваивание большого целого числа в меньший тип
* **C++** (компилируется без вопросов, значения просто усекаются):
  ```cpp
  int bigVal = 100000;
  short shortVal = bigVal; // Произойдет усечение старших бит
  ```
  Пояснение: C++ допускает неявное сужающее преобразование типов. Значение 100000, выходящее за пределы диапазона short (от -32768 до 32767), неявно усекается, и в shortVal записывается результат отбрасывания старших бит, при этом компиляция проходит успешно.
  
* **Java** (ошибка компиляции `incompatible types: possible lossy conversion from int to short`):
  ```java
  int bigVal = 100000;
  short shortVal = bigVal; // Ошибка, нужно писать явный cast: (short) bigVal
  ```
  Пояснение: Java запрещает неявные сужающие преобразования из-за риска потери данных. Для выполнения этой операции необходимо явно указать приведение (short) bigVal, иначе компилятор завершит работу с ошибкой.

### Задание 4 **(1)**
*Рассмотрите следующий фрагмент программы.*

```
bool x = true, y = false;
auto a = x & y;
std::cout << typeid(a).name() << std::endl;
auto b = x && y;
std::cout << typeid(b).name() << std::endl;
```
*Используя* **typeid**, *найдите типы переменных* **a** и **b**. *Объясните результат.*

*Записанную программу сохраните в папке с номером задания.*

**Ответ.**

#### Что выводит программа:
* `typeid(a).name()` выдает `i` (обозначает тип `int`).
* `typeid(b).name()` выдает `b` (обозначает тип `bool`).

#### Объяснение:
1. **Для `a = x & y`:** Значок `&` — это побитовая операция И. По правилам C++ побитовые операции работают только с целыми числами, поэтому операнды `bool` перед вычислением автоматически преобразуются в `int`. На выходе получаем результат типа `int` со значением `0`. Символ `i` как раз означает `int`.
2. **Для `b = x && y`:** Оператор `&&` — это логическое И. Он работает строго с логическими выражениями и всегда возвращает значение типа `bool`. В данном случае выходит `false`, а `typeid` возвращает `b`.

### Задание 6 **(2)**
*Анализ работы программы с неявными преобразованиями типов.*

```cpp
#include <iostream>

int main() {
    int a = -1, b = 1;
    unsigned int c = 1;
    std::cout << a * b << std::endl; // Вывод: -1
    std::cout << a * c << std::endl; // Вывод: 4294967295
    return 0;
}
```

#### 1. Как работает этот код:
* **`a * b`:** Переменные `a` и `b` имеют знаковый тип `int`. Происходит обычное умножение $(-1) \times 1 = -1$.
* **`a * c`:** У переменной `a` тип `int`, а у `c` — `unsigned int`. По правилам языка, если размеры типов одинаковы, знаковое число приводится к беззнаковому. Число `-1` в 32-битном беззнаковом представлении превращается в $2^{32} - 1 = 4294967295$. В итоге умножаем $4294967295 \times 1$ и получаем $4294967295$.

#### 2. Что изменится, если взять `short` и `unsigned short`:
Если переписать переменные как `short a = -1, b = 1;` и `unsigned short c = 1;`, вывод второй строки станет **`-1`**.
* **Причина:** Операции с типами меньше `int` вызывают целочисленное продвижение (Integer Promotion). Перед умножением и `short`, и `unsigned short` сначала приводятся к общему типу `int`. Так как вычисление проходит в рамках знакового `int`, мы получаем ожидаемое $(-1) \times 1 = -1$.

### Задание 7 **(2)**
*Влияние порядка действий и правил преобразования типов на результат.*

```cpp
#include <iostream>

int main() {
    int x = 7, y = 4;
    long double d = 0.25;
    std::cout << (x / y) / d << std::endl; // Вывод: 4
    std::cout << (x / d) / y << std::endl; // Вывод: 7

    long a = 200000, b = 200000;
    long long c = 200000;
    std::cout << (a * b) * c << std::endl; // Вывод: мусор из-за переполнения
    std::cout << a * (b * c) << std::endl; // Вывод: 8000000000000000
    return 0;
}
```

#### Объяснение:

1. **Первый блок:**
   * **`(x / y) / d`:** В скобках делятся два числа типа `int` (`7 / 4`). Дробная часть отбрасывается, получается `1`. Затем `1 / 0.25` с приведением к `long double` дает `4`.
   * **`(x / d) / y`:** В первой скобке делится `int` на `long double`. Переменная `x` сначала превращается в `long double`, и результат получается точным: `7.0 / 0.25 = 28.0`. После этого `28.0 / 4` дает `7`.

2. **Второй блок:**
   * **`(a * b) * c`:** Сначала умножаются `a` и `b` (тип `long`). Значение $200000 \times 200000 = 40 \times 10^9$ не влазит в 32-битный `long` (где лимит около $2 \times 10^9$). Происходит переполнение, и в `c` передается усеченный мусор.
   * **`a * (b * c)`:** Первым вычисляется выражение `(b * c)`. Так как `c` имеет тип `long long`, аргумент `b` приводят к этому же 64-битному типу. Умножение проходит без переполнения, а финальный результат получается правильным: $8 \times 10^{15}$.

### Задание 8 **(2)**
*Анализ логического выражения `(x == y) + (x == z) == true`.*

```cpp
#include <iostream>

int main() {
    int x = 1, y = 1, z = 2;
    std::cout << std::boolalpha << ((x == y) + (x == z) == true) << std::endl;
    return 0;
}
```

#### Как работают преобразования:
1. Выражения `(x == y)` и `(x == z)` возвращают булевы значения `true` или `false`.
2. Операция сложения `+` приводит `bool` к `int`: `true` превращается в `1`, а `false` в `0`.
3. Их сумма может дать `0`, `1` или `2`.
4. Далее полученное целое число сравнивается с `true`. Булево `true` при сравнении с числом кастуется в единицу (`1`). То есть выражение сводится к проверке `Сумма == 1`.

#### При каких значениях выражение будет истинным:
Выражение вернет `true` только тогда, когда выполняется **ровно одно** из двух равенств.
Возможные комбинации:
1. `x == y` и `x != z`
2. `x != y` и `x == z`

*(Если все три переменные равны между собой, то $1 + 1 = 2$. Сравнение $2 == 1$ вернет `false`)*.

### Задание 9 **(2)**
*Сравнение выражения `x == y == z` в Python, Java и C++.*

```python
# Python
x = 1
y = 1
z = 1
print(x == y == z) # Вывод: True
```

```java
// Java
public class Main {
    public static void main(String[] args) {
        int x = 1, y = 1, z = 1;
        // System.out.println(x == y == z); // Ошибка компиляции!
    }
}
```

```cpp
// C++
#include <iostream>

int main() {
    int x = 1, y = 1, z = 1;
    std::cout << std::boolalpha << (x == y == z) << std::endl; // Вывод: true (но это ловушка)
    return 0;
}
```

#### Разбор поведения по языкам:

* **Python:** В языке есть встроенная поддержка **цепочечных сравнений**. Запись `x == y == z` разворачивается компилятором в `(x == y) and (y == z)`. Если все переменные равны `1`, вычисляется `True and True`, поэтому получаем `True`.
* **Java:** Операторы сравнения выполняются слева направо. Сначала считаются скобки `(x == y)`, которые возвращают `boolean` (`true`). Затем Java пытается вычесть `true == z`, то есть сравнить `boolean` и `int`. Из-за строгой типизации такое неявное приведение запрещено, и код даже не скомпилируется.
* **C++:** Выражение тоже вычисляется слева направо: `(x == y) == z`. Сначала вычисляется `(1 == 1)`, что дает `true`. Затем булево `true` неявно кастуется в число `1`, и проверяется равенство `1 == z` (`1 == 1`), возвращая `true`. 

Однако если взять значения `x = 2, y = 2, z = 2`, то `(2 == 2)` вернет `true` (`1`), а потом `1 == 2` даст **`false`**! Так что такая запись в C++ работает корректно по синтаксису, но несет в себе логическую ошибку.
